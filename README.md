# lowdit.github.io

Vitrine publique de l’écosystème Lowdit (HTML statique : `index.html`, `styles.css`, `assets/`).

La source éditoriale et la doc produit (plans modules, lot GitHub Pages) vivent dans le dépôt interne **`lowdit-site/`** du workspace Hugo Lowdit. Après modification de la vitrine, resynchroniser ce dépôt puis pousser sur `main`.

## GitHub Pages

1. **Settings → Pages**
2. **Build and deployment** : **Deploy from a branch**
3. Branche **`main`**, dossier **`/ (root)`**
4. Attendre 1–2 min : [https://lowdit.github.io/](https://lowdit.github.io/)

Aucun build Hugo ni workflow requis pour cette vitrine.
